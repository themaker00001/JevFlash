# .venv-expert (not tracked in git, see .gitignore)

Isolated Python environment for `jevflash/ppo_expert.py` and
`jevflash/build_doom_decisions_ppo.py` (integration of NanoJev's real
frozen Sample Factory PPO checkpoint as a ViZDoom Basic expert).

MUST stay separate from the main `.venv`: `sample-factory` pins an
incompatible `huggingface-hub` version that breaks `transformers`.

Setup:
```bash
python3 -m venv .venv-expert
source .venv-expert/bin/activate
pip install sample-factory vizdoom==1.3.0
git clone --depth 1 https://github.com/alex-petrenko/sample-factory.git /tmp/sample-factory-src
```
(ppo_expert.py adds /tmp/sample-factory-src to sys.path at import time.)

Status as of the initial integration: loads and runs the real checkpoint
correctly (confirmed via their own official enjoy_vizdoom.py script and
directly), and produces visibly reactive, state-dependent behavior --
but measured success rate in our own environment wiring (20-66% across
small samples) doesn't yet match the checkpoint's documented real-world
performance (NanoJev reports 6/6). Likely a remaining rendering/
preprocessing fidelity detail (HUD state, resize method, or observation
normalization edge case) not yet tracked down. Not used for attempt 10;
parked here for whoever wants to pick it up.
